# Traffic Spy


Provides detailed traffic analysis for selected road segments. Displays a breakdown of all agents passing through, categorized by their travel purpose, and also highlights the destination buildings.


Features:

    - Destination Visualization: Highlights destination buildings.

    - Travel Purpose Summary: View vehicle/pedestrian counts, grouped by their travel purpose (e.g., commuting, cargo delivery, etc).

    - Filtering: Isolate specific travel purposes and view only their destinations. Optionally highlight the vehicles/peds themselves.


Known Issues:

    - Pedestrian counts seem high -- need to investigate further.
